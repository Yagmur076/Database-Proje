Kullanılacak Uygulamalar:
  1. MySQL Workbench
  2. Eclipse
  3. JAR (https://dev.mysql.com/downloads/connector/j/)
     //JAR dosyası için "Platform Independent" operating system gerekli, ZIP olarak indirilinecek (2. seçenek)

Nasıl Kullanılıcak:
  1. MySQL Installer'da "Add..." kısmına girip Application kısmında Workbench'in en üstteki sürümü indirilicek.
  2. SQL kodu ayni şekilde yazılıcak.
  3. Eclipse'te Yeni Java projesi üzerinde src dosyasına sağ tık yapıp "New Pakcage" kısmına Java kodu yazılıcak.
  4. İndirilen ZIP'in içindeki "mysql-connector-j" dosyası masaüstüne kopyalanacak.
  5. Masaüstüne kopyalanan JAR dosyası Eclipse Java projesinde src kısmına sürüklenecek.
  6. Son olarak Java kodunun içindeki User_DB ve User_Password kısmı yapan kişinin host ismi ve şifresi ile değiştirilicek.
